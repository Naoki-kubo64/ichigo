# グループホーム 凪（なぎ）

障がい者グループホームのデザイン確認用サイト。HTML / CSS / JavaScript のみで構成しています。ビルドやパッケージのインストールは不要です。

## 構成

- `dist/index.html`：ページ本文・仮の法人情報・料金・FAQ・問い合わせフォーム
- `dist/style.css`：配色・レスポンシブレイアウト
- `dist/script.js`：スマートフォンメニュー・フォームの見本動作
- `dist/assets/home.webp`：AI生成の施設イメージ写真（実在施設の写真ではありません）

## 表示

`dist/index.html` をブラウザで開いて確認できます。Vercelにこのリポジトリをインポートすると、`vercel.json` の設定により `dist` を公開します。Framework Preset は Other、ビルドコマンドは不要です。

## 仮の掲載内容

法人名・代表者・住所・料金・支援内容は仮です。検索エンジン向けに `noindex,nofollow` を設定しています。正式公開前に内容を確定し、この設定を見直してください。

フォームは入力チェックと確認メッセージのみ動作します。送信、保存、メール通知、外部通信は行いません。
